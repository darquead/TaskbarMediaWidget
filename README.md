Стильный, сверхлегковесный прозрачный стеклянный виджет управления мультимедиа для панели задач Windows. Спроектирован специально для бесшовной интеграции с **TranslucentTB** (в режимах `Clear` и `Acrylic`), живыми анимированными обоями **Wallpaper Engine** и нативным Fluent-дизайном Windows 11 и 10.

---

## 🌟 Возможности (Features)

- **💎 Прозрачный стеклянный дизайн (Fluent Glass)**:
  - 32-битный аппаратно-ускоренный DWM Layered Window с альфа-прозрачностью и ультратонкой световой каймой.
  - Тонкий радиус скругления 5 px без громоздких капсул — органично смотрится на панели задач и живых обоях.
  - Никаких грязных размытых теней: текст и кнопки выводятся кристально чётко.
- **🖼 Фото обложки альбома (Album Cover Art)**:
  - Отображает реальную обложку текущего трека (26×26 px со скруглением и обводкой), извлекаемую на лету из потока Windows System Media Transport Controls (SMTC).
  - При отсутствии обложки отображается стильная стеклянная плитка с нотой.
- **🔊 Умная регулировка громкости колесиком мыши (App-Specific Volume)**:
  - Прокрутка колёсика мыши над виджетом изменяет громкость **именно того приложения, из которого сейчас играет звук** (через Windows Audio WASAPI Session Control и Peak Metering).
  - Если активна музыка, регулирует Spotify / Яндекс Музыку / плеер. Если звук идёт из браузера — регулирует вкладку/браузер.
  - На виджете плавно всплывает обратная связь: `🔊 Spotify: 75%`.
- **📍 Адаптивное позиционирование панели задач**:
  - **Кнопка «Пуск» по центру** (Windows 11 по умолчанию): виджет размещается ровно слева от кнопки Windows, автоматически смещаясь вместе с ней.
  - **Кнопка «Пуск» в левом углу** (Windows 10 / режим Left / StartAllBack): виджет автоматически занимает **геометрический центр панели задач**.
  - **Вертикальная панель задач** (слева или справа экрана): виджет автоматически поворачивается **на 90° по часовой стрелке** (включая обложку альбома, текст и кнопки), сохраняя полную интерактивность кликов.
- **🖥 Два режима отображения (Desktop & Taskbar)**:
  - **Режим «Панель задач» (Taskbar)**: виджет надёжно закреплён поверх панели (`HWND_TOPMOST`), автоцентрируется и блокирует случайное перемещение.
  - **«Свободный режим» (Desktop Mode)**: окно свободно перетаскивается зажатием ЛКМ (DragMove) в любую точку экрана. Располагается на системном уровне `HWND_BOTTOM` — **строго НАД обоями Wallpaper Engine**, но **ПОД всеми окнами приложений** (не перекрывает браузер, Telegram, игры).
- **🎧 Динамическая иконка в трее (Studio Headphones)**:
  - Стильный значок студийных мониторных наушников на тёмном сквиркле с неоновой бирюзовой дужкой.
  - Отображает статус воспроизведения: при воспроизведении между чашами пульсируют неоновые звуковые волны, на паузе — аккуратный значок ожидания.
- **🎛 Продвинутое контекстное меню (ПКМ)**:
  - **Автозакрытие**: мгновенно закрывается при клике в любое место вне меню.
  - **«Настройка шрифта...»**: стандартный `FontDialog` для выбора любого установленного шрифта, начертания (Bold / Italic) и размера в реальном времени.
  - **Ползунок «Прозрачность»**: плавный слайдер 10%–100% с живым изменением прозрачности окна.
  - **Компактный режим**: переключение в один клик между полным (330 px) и минималистичным (116 px) режимами.
- **🚀 100% Portable & Автозапуск**:
  - Полностью портативное приложение: хранит настройки (`config.ini`) и журнал (`run.log`) прямо в папке с программой.
  - При первом запуске автоматически прописывается в автозагрузку Windows пользователя (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`), привязываясь к текущему пути к файлу.

## 🎮 Управление (Controls)

| Действие | Назначение |
|---|---|
| **ЛКМ по ⏮ / ▶ / ⏸ / ⏭** | Предыдущий трек, Воспроизведение / Пауза, Следующий трек |
| **Колесико мыши над виджетом** | Увеличение / уменьшение громкости звучащего приложения (шаг 5%) |
| **ЛКМ по названию / обложке** | Вывести окно плеера (Spotify, браузер и т.д.) на передний план |
| **Зажатие ЛКМ (в Свободном режиме)** | Плавное перетаскивание виджета по рабочему столу (DragMove) |
| **ПКМ по виджету или иконке трея** | Открыть контекстное меню настроек |
| **Наведение курсора на название** | Плавная бегущая строка (Marquee) для длинных названий треков |

## ⚙️ Конфигурация (`config.ini`)

Файл настроек генерируется автоматически рядом с исполняемым файлом:

```ini
# TaskbarMediaWidget Configuration
CompactMode=False
EnableVolumeWheel=True
MarginGap=8
AutoStart=True
FreeMode=False
FreeX=100
FreeY=100
OpacityPercent=100
FontFamilyName=Inter
FontSize=10.2
FontBold=False
FontItalic=False
```

## 🛠 Сборка из исходного кода (Build)

Для сборки **не требуется Visual Studio** — достаточно стандартного компилятора C#, встроенного в Windows:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/TaskbarMediaWidget.git
   cd TaskbarMediaWidget
   ```
2. Запустите скрипт сборки в PowerShell:
   ```powershell
   powershell -ExecutionPolicy Bypass -File build.ps1
   ```
3. Готовый бинарник будет находиться в каталоге `dist\TaskbarMediaWidget.exe`.

## 📦 Структура проекта

```text
TaskbarMediaWidget/
├── app.manifest           # Манифест PerMonitorV2 DPI Awareness и совместимости с Win 10/11
├── build.ps1              # Автономный скрипт сборки через стандартный csc.exe
├── AppVolumeManager.cs    # Управление громкостью конкретных приложений (WASAPI & Peak Meter)
├── Config.cs              # Портативное хранение настроек, автозапуск, пути
├── MediaEngine.cs         # Взаимодействие с WinRT SMTC, обложки треков, медиа-клавиши
├── Program.cs             # Точка входа, SingleInstance Mutex, ротация логов
├── TrayContext.cs         # Системный трей, динамическая иконка наушников
├── WidgetForm.cs          # Стеклянный layered виджет, свободный режим, поворот на 90°
├── fonts/                 # Встроенные шрифты (Inter)
├── dist/                  # Скомпилированный дистрибутив
├── LICENSE                # Лицензия MIT
└── README.md              # Документация проекта
```
