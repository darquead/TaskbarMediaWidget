Стильный, сверхлегковесный прозрачный стеклянный виджет управления мультимедиа для панели задач Windows. Спроектирован специально для бесшовной интеграции с **TranslucentTB**, живыми обоями **Wallpaper Engine** и нативным дизайном Windows 10 / 11.

*A sleek, lightweight transparent glass media control widget for the Windows taskbar with Wallpaper Engine and TranslucentTB support.*

---

## 🌟 Возможности / Features

- **💎 Fluent Glass**: Прозрачный стеклянный дизайн без лишних теней, идеально сочетается с чистой панелью задач и живыми обоями.
- **🖼 Обложка альбома (Cover Art)**: Автоматическое извлечение реальной обложки текущего трека из Windows Media (SMTC).
- **🔊 Умная регулировка громкости (Smart Volume)**: Прокрутка колёсика мыши изменяет громкость именно того приложения, которое сейчас играет (Spotify, браузер, плеер).
- **📍 Адаптивное позиционирование (Adaptive Docking)**: Автоматическое центрирование на панели задач (Windows 10/11) и поддержка вертикальной панели (поворот на 90°).
- **🖥 Свободный режим (Free Desktop Mode)**: Перемещение в любую точку экрана; виджет крепится поверх живых обоев, не перекрывая рабочие окна и панель задач.
- **🎧 Динамический трей (Dynamic Tray)**: Иконка наушников со статусом воспроизведения в реальном времени.
- **🌐 Мультиязычность (RU / EN)**: Быстрое переключение языка интерфейса через меню по ПКМ.
- **🎛 Настройки по ПКМ**: Выбор шрифта, плавный ползунок прозрачности (10–100%) и компактный режим.
- **🚀 100% Portable**: Никаких следов в системе — все настройки и логи хранятся исключительно в папке с программой.

## 🎮 Управление / Controls

| Действие (Action) | Назначение (Description) |
|---|---|
| **ЛКМ по ⏮ / ▶ / ⏸ / ⏭** | Предыдущий трек, Воспроизведение / Пауза, Следующий трек (Media controls) |
| **Колесико мыши над виджетом** | Увеличение / уменьшение громкости звучащего приложения (App volume wheel) |
| **ЛКМ по названию / обложке** | Вывести окно плеера (Spotify, браузер и т.д.) на передний план (Focus player window) |
| **Зажатие ЛКМ (в Свободном режиме)** | Плавное перетаскивание виджета по экрану (DragMove) |
| **ПКМ по виджету или иконке трея** | Открыть контекстное меню настроек и ссылку на профиль автора (Context menu) |
| **Наведение курсора на название** | Плавная бегущая строка для длинных названий треков (Marquee on hover) |
