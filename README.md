Стильный, сверхлегковесный прозрачный стеклянный виджет управления мультимедиа для панели задач Windows. Спроектирован специально для бесшовной интеграции с **TranslucentTB**, живыми обоями **Wallpaper Engine** и нативным дизайном Windows 10 / 11.

---

## 🌟 Возможности

- **💎 Fluent Glass**: Прозрачный стеклянный дизайн без лишних теней, идеально сочетается с чистой панелью задач и живыми обоями.
- **🖼 Обложка альбома**: Автоматическое извлечение реальной обложки текущего трека из Windows Media (SMTC).
- **🔊 Умная регулировка громкости**: Прокрутка колёсика мыши изменяет громкость именно того приложения, которое сейчас играет (Spotify, браузер, плеер).
- **📍 Адаптивное позиционирование**: Автоматическое центрирование на панели задач (Windows 10/11) и поддержка вертикальной панели (поворот на 90°).
- **🖥 Свободный режим (Desktop)**: Перемещение в любую точку экрана; виджет крепится поверх живых обоев, не перекрывая рабочие окна.
- **🎧 Динамический трей**: Иконка наушников со статусом воспроизведения в реальном времени.
- **🎛 Настройки по ПКМ**: Выбор шрифта, плавный ползунок прозрачности (10–100%) и компактный режим.
- **🚀 100% Portable**: Никаких следов в системе — все настройки и логи хранятся исключительно в папке с программой.

## 🎮 Управление

| Действие | Назначение |
|---|---|
| **ЛКМ по ⏮ / ▶ / ⏸ / ⏭** | Предыдущий трек, Воспроизведение / Пауза, Следующий трек |
| **Колесико мыши над виджетом** | Увеличение / уменьшение громкости звучащего приложения |
| **ЛКМ по названию / обложке** | Вывести окно плеера (Spotify, браузер и т.д.) на передний план |
| **Зажатие ЛКМ (в Свободном режиме)** | Плавное перетаскивание виджета по экрану (DragMove) |
| **ПКМ по виджету или иконке трея** | Открыть контекстное меню настроек и ссылку на профиль автора |
| **Наведение курсора на название** | Плавная бегущая строка (Marquee) для длинных названий треков |
